# 记忆提取模板（memories_extract.md，§5.4）

你是记忆蒸馏引擎。任务：**逐条阅读**下面给出的对话片段（分段蒸馏的完整原文，不允许跳过），结合统计摘要，提取发送者 B（她）的记忆骨架：阶段摘要 + 情绪曲线 + 代表节点（附原文证据）+ 口癖统计验证 + 关系温度。

## 输入

### 对话片段（段 {{SEGMENT_ID}}/{{TOTAL_SEGMENTS}}）
```
{{SEGMENT_TEXT}}
```

### 统计摘要
```
{{STATS}}
```

## 输出要求

只输出一个 JSON 对象（不要输出任何其他文字），结构如下：

```json
{
  "segment_summary": "本段阶段摘要（这段时期发生了什么、关系温度如何）",
  "emotion_curve": [{"ts": "时间点", "level": -10到10的数字, "note": "说明"}],
  "timeline": [
    {"stage": "阶段名", "start": "起", "end": "止", "temperature": "温度描述",
     "events": ["代表性事件（带原文）"]}
  ],
  "nodes": [
    {"event": "事件一句话", "ts": "时间", "emotion": -10到10, "importance": 0到1,
     "evidence": "完整原文证据（verbatim）", "tags": {"entities": ["实体"], "situations": ["情境"],
     "world": "世界归属", "platform": "wechat"}}
  ],
  "daily_patterns": [
    {"pattern": "固定仪式/频率/中断（如：每天睡前互道晚安；周末消失）", "evidence_level": "artifact|verbatim"}
  ],
  "unfinished": [
    {"promise": "未兑现的约定", "ts": "约定时间", "evidence": "原文"}
  ],
  "entity_clusters": [
    {"entity": "实体名", "aliases": ["别名，含指代归并"], "world": "学习世界|家庭世界|你们的世界|兴趣世界",
     "situations": ["关联情境"], "platform": "wechat",
     "memories": [{"event": "相关记忆一句话", "evidence": "原文截断", "emotion": 数值, "importance": 数值}]}
  ],
  "conflicts": [{"issue": "无法裁决的矛盾", "versions": ["可能版本"]}]
}
```

## 硬规则（必须遵守）

1. **每个节点可追溯到原文**：evidence 必须是原文（verbatim），不是转述。
2. **时间线用完整时间保证可回溯**。
3. **口癖统计验证**：结合统计摘要的高频词，验证/修正表达层结论（统计数字与原文对照，数字错了以原文为准并说明）。
4. **代表节点**：重要节点=对关系有意义的时刻（初识/转折/争吵/和解/纪念日/深夜长谈…），不是每条都收；宁缺毋滥。
5. **情感值**：-10~10（负=负面情绪）；**重要性**：0~1（关键节点永远清晰）。
6. **世界树标签（4.2 必需）**：实体（人/地点/物件/动物/学校/食物…）、情境（深夜/忙碌/假期/压力期/纪念日/吵架后）、世界归属（学习世界/家庭世界/你们的世界/兴趣世界）、平台（wechat/douyin/qq…）。**识别指代**（"它今天又挠沙发了"→"它"归入实体簇"猫"）、**同义归一**（"咪咪/橘猫/那只猫"→同一实体簇别名）。实体别名表随本段产物产出，检索时按别名扩展命中。
7. **不确定写"不确定"**；与人格提取冲突的点写入 conflicts（不删除、不掩盖）。
8. **默认完整**：用户自己的数据，完整引用是质量要求。
9. 每条结论附证据分级（verbatim/artifact/impression）；无证据推断不进本输出（留给 merge 阶段进推测区）。
